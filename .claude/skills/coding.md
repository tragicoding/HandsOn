# code-generation
## Description
- agent가 code를 생성, 수정, 삭제 할 시에 이 skills를 참고하여 수행한다.

## 핵심 규칙
- docs\PRD.md , docs\requirements.md 의 문서를 반드시 가장 먼저 읽고 프로젝트를 파악한다.

## intstruction
- agent는 아래 항목 중 해당하는 상황이라면, 규칙을 따른다. 

### 1. 디렉토리 생성
- root 디렉토리는 `HandsOn` 이다.
- 디렉토리별, 파일별로 책임분리 경계가 확실해야 한다.
- 새로운 파일을 만들 때 다른 파일과 같은 역할을 하는 파일인지 확인하고, 이미 같은 역할의 파일이 있다면 기존에 있었던 파일을 대상으로 임무를 수행한다.
- sorce code의 최상위 디렉토리는 HandsOn/src/ 이다.

### 2. 코드 작성
- 주석은 한글로 작성한다. 
- 기능에 대하여 파일별로 분리하여 책임분리 경계를 명확히 한다.
- 코드를 작성하거나 추가할 때, 기존에 그 기능을 하는 코드가 있다면 다시 작성하지 않고 수정해야 한다면 기존의 코드를 수정한다.
    - 만약 반드시 추상화 등의 이유로 새로 작성해야 한다면 기존 코드를 지운다. 코드를 지울 때는 기존의 시스템이 안전하게 유지되는지 확인한다. 
- 하나의 파일에 함수가 여러개 작성되는 경우, 100줄이 넘어갈 경우에는 여러 파일에 분산하여 함수를 작성한다. 이때, 의존관계는 확실하게 연결한다. 

- 함수별로 주석은 필수이며, 다음 내용들을 포함한다.
    - 기능 및 역할
    - 핵심 로직
