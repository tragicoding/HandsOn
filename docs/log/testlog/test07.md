## 해석
- phase0는 PRD가 정한 기본 흐름(참여자 → 지출 → 정산 → 송금 → 복사, 저장, 모바일 폭)은 동작한다. 정산 불변식(합계 일치, 차액합 0, 송금 횟수 ≤ 인원-1)도 모두 PASS.
- 이후 phase에서 추가된 감면, 잔여 처리, 비활성화, 입력 검증, 동명이인 구분, 결제자 포함 검사가 모두 없다.
