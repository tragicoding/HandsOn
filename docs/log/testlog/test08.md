> 용어
> - **data-theme**: `<html>` 태그에 붙이는 이름표(`light` 또는 `dark`). 이 값이 바뀌면 CSS의 색상 변수가 통째로 바뀌어서 화면 전체 색이 한 번에 바뀐다.
> - **hover**: 마우스 커서를 버튼 위에 올린 상태.
> - **inert**: "지금은 누르거나 탭으로 이동할 수 없음"을 뜻하는 표시. 시작 화면이 떠 있는 동안 뒤의 메인 화면에 붙여 둔다.

## 동작 흐름

```
앱 열기
  │  (index.html 맨 위 작은 스크립트)  저장된 모드가 있으면 그것, 없으면 기기 설정 -> data-theme 적용
  v
[ 시작 화면 ]  Dutch Pay 문구 / 캐릭터(가운데) / [다크 모드] [화이트 모드] / [시작하기]
  │   다크 모드 버튼   -> data-theme="dark"  (색이 즉시 바뀜, 브라우저에 저장)
  │   화이트 모드 버튼 -> data-theme="light" (색이 즉시 바뀜, 브라우저에 저장)
  v
시작하기 -> 시작 화면이 부드럽게 사라짐 -> [ 메인 화면 ]  (현재 모드 그대로)
```
