
- 현재 처리: 감면을 무시하고 균등 분배 (합계는 항상 총액과 일치).

- 오류 메시지(상황)
```
지출: 80,000원 / 참여자 A,B,C  ->  C를 비활성화
```
- 예상 원인: PRD에 "비활성화된 참여자의 과거 지출 처리"가 없음.

- 예상 해결방법: 비활성화 시 "기존 지출에서 제외 / 유지" 선택을 명세서에 정의.
